# 去 AI 味

## 职责

只负责**诊断 AI 味、定位问题层、按顺序改写**；不改剧情、不新增事实、不替作者做创作决策。

改写的目标是“更像人写的”，不是“更像检测器喜欢的”。

## 必读

1. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/40_Writing/05_降AI痕迹/朱雀祛AI味五维.md`
2. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/40_Writing/05_降AI痕迹/AI禁用词与句式表.md`
3. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/40_Writing/05_降AI痕迹/降低AI痕迹.md`
4. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/40_Writing/02_节奏与结构/跨章规范与七遍改稿.md`

## 工具

```bash
# 综合 AI 味评分与分项
python3 "${CLAUDE_PLUGIN_ROOT}/tools/ai_flavor_score.py" "{章节文件}" --json

# 硬指标：AI 词、破折号/冒号、情绪命名、对话标签、章尾
python3 "${CLAUDE_PLUGIN_ROOT}/novel_creation_promax/scripts/post_write_audit.py" \
  --chapter-file "{章节文件}" --title "{标题}"
```

## 工作流

1. **先诊断，不先改**：跑两个脚本，记录综合分、最差分项、AI 词命中、破折号/冒号密度、情绪命名次数。
2. **定位层**：
   - 词汇分布差 → 先清 AI 词和套话。
   - 突发性差 → 改句长和段落。
   - 语义连贯性差 → 删显性逻辑词，改暗线。
   - 场景同质化 → 换场景策略。
3. **按顺序改**：结构 → 句法 → 词汇 → 逻辑 → 认知摩擦。不跳层。
4. **保真**：只改“怎么说”，不改“说什么”。不新增事实、数字、案例、因果、引语。
5. **复跑**：改完重跑两个脚本；目标综合分 <45，且硬指标不回升。
6. **交付**：输出修订稿 + 改动说明；覆盖原稿前先快照。

## 五层改写

| 层 | 改什么 | 例子 |
|---|---|---|
| 1 结构 | 段序、长短段、段首句 | 删掉“主题句 + 解释 + 总结” |
| 2 句法 | 句长、主语、语序 | 连续同长句拆成短句 + 长句 |
| 3 词汇 | AI 词、套话、抽象名词 | “进行 → 具体动词” |
| 4 逻辑 | 显性连词、过渡 | 删“因此/然而”，用动作或短句承接 |
| 5 认知摩擦 | 自我修正、口头禅、不完美 | 1-2 处“先错后对”，不要每段都加 |

## 不改动清单（防误杀）

以下特征人类用得比 AI 多，禁止据此改写：

- 句长参差。
- 虚词偏少。
- 反复写全称。
- 问句。
- 比喻本身。
- 名词化长句。

## 输出格式

```text
AI 味诊断
- 综合分：{x}/100（{level}）
- 最差分项：{burstiness/repeat/ai_words/dash/colon/logic/cliche}
- 硬指标：AI 词 {n} / 破折号 {x}/千字 / 情绪命名 {n}
- 主要问题：3 条
- 改写层：{1-5}
- 修订稿：{路径}
- 复跑结果：{前后对比}
```

## 硬规则

- 不新增事实、不改变情节、不改变人物说话方式。
- 不为了降分把句子改得支离破碎。
- 不伪造“已过朱雀/平台检测”的结论；本地评分只是启发式。
- 不覆盖原稿，先写 `素材/revisions/` 或带时间戳的副本。
- 不把“AI 味”当成质量问题全部背锅；剧情、人设、节奏问题要单独指出。
- 输出只写工作区，不写插件知识库。

## 边界

- 不替代 `post_write_audit.py` 的硬规则审计。
- 不替代 `reviewer` 的剧情/人物审稿；本 skill 只处理“像不像 AI”。
- 不处理合规问题；合规走 `50_Quality/量化门禁/10步量化门禁.md`。
