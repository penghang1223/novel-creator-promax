# 短剧改编评估与分集设计

判断一本书能不能改成短剧/漫剧，并把可改的部分拆成分集结构。

## 边界

| 拥有 | 不拥有 |
|---|---|
| 改编潜力评估、分集大纲、钩子表、改编风险 | 正文改写、设定变更、售出承诺 |

- 只读正文、细纲、人物档案和真相文件；产物写入工作区 `素材/短剧/`。
- 只做“改编设计”，不替作者改小说；需要改正文时回到写章流水线。
- 不承诺平台收购、保底或收益。

## 必读

1. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/40_Writing/07_短篇与模板/短剧改编10维.md`
2. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/40_Writing/07_短篇与模板/短剧改编指南.md`
3. `${CLAUDE_PLUGIN_ROOT}/novel_creation_promax/references/docs/short-drama-adaptation.md`
4. `${CLAUDE_PLUGIN_ROOT}/novel_creation_promax/references/docs/drama-storytelling.md`
5. 项目章程、结构目录下的主线结构文档、细纲目录

## 输入

先确认：

- 书名与评估范围（全本 / 前 N 章 / 某一卷）
- 目标形态：竖屏短剧（1-3 分钟/集）/ 漫剧 / 中剧
- 目标平台与集数区间
- 是否已有改编意向或预算约束

## 执行

1. **10 维评估**：逐维打分并给证据（原文位置），不只给结论。维度以知识库的「短剧改编10维」文档为准。
2. **改编路径**：给出“直接改编 / 压缩主线 / 只取单元 / 不建议改编”之一，并说明理由。
3. **分集地图**：按目标形态拆集，每集写 `核心事件 / 开场钩子 / 中段反转 / 结尾钩子 / 情绪峰值`。
4. **钩子表**：列 `集数 | 开场 3 秒 | 中段冲突 | 结尾钩子 | 钩型`，检查钩型轮换，避免连续同型。
5. **成本与限制**：标出高成本场景（大场面、群演、特效、特殊地点），给替代拍法。
6. **风险清单**：审核风险、改编丢失、节奏塌陷、人物动机不成立，逐项给应对。

## 输出

```text
${CLAUDE_PROJECT_DIR}/素材/短剧/{书名}/
├── 改编评估.md
├── 分集大纲.md
├── 钩子表.md
└── 改编风险.md
```

`改编评估.md` 固定包含：

```text
## 结论
- 建议：直接改编 / 压缩主线 / 只取单元 / 不建议
- 目标形态：
- 建议集数：
- 一句话卖点：

## 10 维评分
| 维度 | 分数 | 证据 | 风险 |

## 必须保留
## 可以合并
## 必须舍弃
## 不确定项（需作者确认）
```

## 硬规则

- 评分必须有原文证据；没有证据的维度标“证据不足”，不给高分。
- 不承诺改编售出、平台采购或收益。
- 不擅自改正文；需要改时列出“改编前置修改清单”，交回写章流程。
- 集数、时长、钩子密度必须匹配目标形态，不套用长篇章节节奏。
- 涉及真实人物、真实事件、敏感题材时，先列审核风险，不做规避审核的指导。

## 禁止事项

- 不把短剧产物写回正文或设定目录。
- 不伪造平台采购意向、保底金额或售出记录。
- 不给出规避内容审核、洗稿或侵权改编的方案。
- 不在证据不足时给出“强烈建议改编”的结论。
