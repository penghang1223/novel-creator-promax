# 动漫分镜与视觉提示词

把文字转成可执行的视觉指令，不重写小说正文。

## 边界

| 拥有 | 不拥有 |
|---|---|
| 角色形象、场景提示词、Sora/即梦分镜、分镜表 | 正文改写、剧情增删、设定变更 |

- 只读正文、细纲、人物档案和真相文件；产物写入工作区 `素材/分镜/`。
- 画面信息不足时标注“原文未描述”，不要替作者补设定。
- 不复制知名动漫/影视角色的外貌与标志性设计。

## 必读

1. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/动漫分镜生成.md`
2. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/40_Writing/04_场景与描写/场景描写技法.md`（存在则读）
3. 项目设定目录下的人物档案、地点档案，以及真相文件中的 characters.json
4. 对应章节正文与细纲

## 输入

先确认，缺省时给推荐值：

- 书名与章节范围（默认当前章）
- 目标形态：竖屏短剧 / 漫剧 / 动画预告 / 静态分镜
- 画风：写实 / 国漫 / 日系 / 水墨 / 赛博
- 输出深度：只要提示词 / 提示词 + 分镜表 / 全量

## 执行

1. **场景切分**：按“地点 + 时间 + 人物 + 冲突”把章节拆成 6-12 个镜头场景；每个场景标注原文位置。
2. **角色形象**：从人物档案提取年龄、身份、服装、体态、标志性动作；缺失项标“原文未描述”。同一角色跨场景保持同一套外观锚点。
3. **场景提示词**：每个场景输出双段式描述——环境段（地点、光线、天气、陈设）+ 人物段（动作、表情、镜头关系）。
4. **Sora 分镜**：输出 JSON 数组，每项包含 `shot_id`、`duration`、`camera`、`subject`、`action`、`environment`、`lighting`、`prompt`。
5. **分镜表**：Markdown 表格，列固定为 `镜号 | 时长 | 景别 | 机位 | 画面内容 | 台词/音效 | 转场`。
6. **一致性检查**：角色外观、地点陈设、时间线三项逐项核对；冲突项先报告，不自行改设定。

## 输出

```text
${CLAUDE_PROJECT_DIR}/素材/分镜/{书名}/
├── 角色形象.md
├── 角色提示词.md
├── 场景提示词.md
├── sora_分镜.json
└── 分镜表.md
```

文件头统一写：

```text
> 来源：{书名} 第{N}章 · 生成日期：{YYYY-MM-DD}
> 画风：{画风} · 目标形态：{形态}
> 说明：角色/场景信息来自正文与设定；标“原文未描述”的项需作者确认。
```

## 硬规则

- 不改正文、不改设定、不新增剧情。
- 角色外观必须与人物档案一致；档案没有的，标“原文未描述”，不得编造。
- 分镜时长与镜头数要匹配目标形态：竖屏短剧单镜 2-5 秒，漫剧单镜 3-8 秒。
- 提示词里不出现真实明星、导演、受版权保护的角色名。
- 输出前检查：每个场景是否有地点、人物、动作、镜头；缺一项就补问，不要空镜。

## 禁止事项

- 不把分镜产物写回正文或设定目录。
- 不为缺失的外观信息编造设定。
- 不复制知名动漫、影视、游戏角色的标志性设计。
- 不承诺分镜可直接商用或通过平台审核。
