# 章节钩子

## 职责

只负责**章首钩子、章末钩子、章中微钩子和钩型轮换**；不写完整正文、不改剧情走向。

钩子不是“留个悬念”，而是让读者产生一个具体的、必须翻页才能解决的压力。

## 必读

1. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/40_Writing/01_开篇技巧/开头钩子库.md`
2. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/30_Plot/叙事结构与场景节点.md`
3. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/40_Writing/03_人物与对话/句式骨架与提示词库.md`
4. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/40_Writing/06_质量校验/章节节奏R1-R8.md`
5. 上一章正文结尾 500 字 + 本章细纲

## 工具

```bash
# 检查成稿的章末形态、前 300 字、AI 词
python3 "${CLAUDE_PLUGIN_ROOT}/novel_creation_promax/scripts/post_write_audit.py" \
  --chapter-file "{章节文件}" --title "{标题}"

# 跨章检查连续弱钩子（R4）
python3 "${CLAUDE_PLUGIN_ROOT}/tools/chapter_rhythm.py" \
  --table "{作战表}" --check
```

## 工作流

1. **读上一章结尾**：确认上章留下了什么未完成压力。
2. **定本章情绪**：爆章、冷章、过渡章，钩型必须匹配。
3. **选章末钩型**：从 H1-H12 选 1 个主钩，至少 1 个备选。
4. **设计章首 3 句**：异常 / 代价 / 反应，避免天气、梦醒、日常起床。
5. **布置微钩子**：每 500 字 1 个，信息缺口 / 异常细节 / 小倒计时，交替使用。
6. **检查轮换**：相邻两章不同型；同卷同型 ≤4 次；连续弱钩子不超过 3 章。
7. **成稿检查**：跑 `post_write_audit.py`，看章尾是否反问/感叹/平收。
8. **输出方案**：钩型、位置、句式骨架、必须结算的承诺。

## H1-H12 章末钩型

| 型 | 钩子 | 适合情绪 |
|---|---|---|
| H1 | 未完成行动 | 冷章、过渡章 |
| H2 | 意外信息 | 中章、调查章 |
| H3 | 不可撤回选择 | 爆章、转折章 |
| H4 | 后果扩大 | 升级章 |
| H5 | 身份揭穿 | 爆章 |
| H6 | 规则失效 | 爆章、世界观转折 |
| H7 | 时间压迫 | 紧张章 |
| H8 | 关系反转 | 情感章 |
| H9 | 代价显形 | 兑现章 |
| H10 | 目标转移 | 换挡章 |
| H11 | 视角切换 | 悬疑/多线 |
| H12 | 悬置动作 | 冷章、爆章皆可 |

## 输出格式

```text
本章钩子方案
- 章首：{三句骨架}
- 章中微钩子：{位置 + 类型 + 结算章}
- 章末：{H型 + 具体画面/台词}
- 备选钩：{H型 + 一句话}
- 必须结算：{承诺/伏笔/问题}
- 轮换检查：{上一章型 → 本章型 → 下一章建议}
```

## 硬规则

- 章末禁反问、感叹、总结、抒情、升华。
- “第X章完”不能作末句。
- 钩子必须在本章或后文结算，不许埋了不管。
- 不许用“第二天早上”“与此同时”作为默认转场。
- 不许把下一章的核心事件提前泄底。
- 钩子必须与本章情绪匹配；冷章不要硬塞生死危机。

## 边界

- 只做钩子方案和成稿检查；正文仍走 `novel-chapter-write` 流水线。
- 不改细纲主线；要改关键钩子节点，先按细纲偏离协议说明。
- 输出只写工作区章节文件或 `素材/` 报告，不写插件知识库。
