# 创意生成

目标不是列点子的标题，而是产出**能立项的创意卡**：一句话讲得清、冲突立得住、爽点撑得久、风险说得明。

## 输入

先确认，缺省时给推荐值：

- 平台：番茄 / 起点 / 知乎盐选 / 七猫 / 不限
- 题材偏好：玄幻 / 都市 / 悬疑 / 言情 / 年代 / 脑洞 / 混合
- 受众：男频 / 女频 / 不限
- 篇幅：短篇 / 中篇 / 长篇
- 数量：默认 5 个，最多 10 个
- 禁忌：不想写的套路、不能碰的题材

## 必读

1. 最近一次同平台调研：`${CLAUDE_PROJECT_DIR}/素材/调研/*{平台}*.md`（存在则读最近一份）
2. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/50_Quality/创意五维评分.md`
3. `${CLAUDE_PLUGIN_ROOT}/knowledge_base/30_Plot/创意策划通用框架.md`
4. `${CLAUDE_PLUGIN_ROOT}/novel_creation_promax/references/stages/01-idea/idea-interaction.md`
5. 题材画像：`${CLAUDE_PLUGIN_ROOT}/knowledge_base/10_WorldBuilding/题材知识库/{题材}.md`

没有调研报告时，先说明“本次基于知识库基线生成”，不要虚构市场数据。

## 生成规则

每个创意必须包含：

- 一句话 logline：主角 + 处境 + 目标 + 阻力 + 反差
- 核心反差与钩子
- 主角四维：动机 / 能力 / 缺陷 / 成长弧光
- 金手指或核心设定，必须有**限制与代价**
- 核心爽点与主情绪
- 开篇三章钩子
- 类型对标与差异点
- 主要风险：同质化 / 审核 / 执行难度

差异化要求：

- 5 个创意至少覆盖 3 种不同的核心情绪或爽点结构，不能只换皮。
- 每个创意至少有一个“别人没写过或很少写”的具体切口。
- 对标只写类型或作品名，禁止复制角色名、专有设定和原文。
- 先有冲突和情绪，再叠设定；禁止用设定堆砌冒充创意。

## 评分

每个创意用五维评分：

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/tools/idea_score.py" --input "{创意卡JSON}" --json
```

权重：创新 10%、市场 25%、可读 20%、情绪 25%、商业 20%。

- 总分 ≥ 75 且没有维度低于 8：推荐立项
- 总分 ≥ 75 但存在低于 8 的短板：可立项，先补短板
- 60–74：可立项，但需补强
- < 60：不推荐立项，说明原因

## 输出

使用模板：

`${CLAUDE_PLUGIN_ROOT}/novel_creation_promax/references/templates/idea_card.md`

写入工作区：

```text
${CLAUDE_PROJECT_DIR}/创意/创意卡_{YYYY-MM-DD}.md
```

报告结构：

1. 排序表：名称 / 总分 / 等级 / 主爽点 / 最大风险
2. 每个创意的完整创意卡
3. 推荐前 3 与推荐理由
4. 下一步：用户选定后交给 `novel-project-planning` 立项

## 硬规则

- 一次最多 10 个；用户没指定时给 5 个。
- 不生成低俗、侵权或明显违规的创意。
- 不虚构市场数据；引用调研报告或标 `[待验证]`。
- 评分低于 60 的创意不得包装成“推荐”。
- 用户选定后，先进入立项流程，不要直接写正文。
