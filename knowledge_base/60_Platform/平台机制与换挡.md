# 平台机制与换挡

> 用途：理解平台"怎么分发"，以及同一本书换平台时改哪些参数。
> 时效：机制数字采集于 2026-08/09，平台规则会变；发布前以平台最新官方说明为准。
> 字数纪律：本项目字数区间以 `knowledge_base/60_Platform/_PROFILES.json` 为准；本文件只讲机制与换挡。

## 一、分发四步（通用逻辑）

1. **标签分层**：系统从书名、简介、正文抽词打标，决定进哪个赛道。
2. **同赛道赛马**：同标签的新书放在一起比同期表现，不是跟全站比。
3. **流量池递进**：表现好进下一层池，表现差留在原池直到消耗完。
4. **行为放量**：点击、完读、书架、追更四个行为决定是否继续给量。

推论：数据不好不一定是书写得差，可能是**标签打错了**——推给了不看这类书的人。诊断时先确认标签。

## 二、番茄关键机制（2026-09 口径）

### 三关制

| 关 | 节点 | 说明 |
|---|---|---|
| 签约 | 2/5/8 万字三次机会 | 通过率约 60%；建议 3 万字再申请 |
| 验证 | 7 天 | 书架比、追更比是核心；连续 5 天达标才算过 |
| 首秀 | 21 天 | 前 10 章完读 + 7 日追更决定进哪层池 |

### 六层流量池

0-8 万 / 8-10 万 / 10-50 万 / 50-80 万 / 80-100 万 / 100 万+。

每层考核项不同，所以"在 L2 阶段优化 L5 的问题"是无效劳动。

### 四条断流红线

1. 断更 ≥3 天。
2. 修改已发布章节（数据归零）。
3. 22-24 点更新（进入次日池，等同于延迟）。
4. 8 万字评估三次全败。

### 书测节点

20-50 万字一次，100 万字后一次。5 套素材，观察 7-10 天。

### AI 使用边界（2026-08 治理公告口径）

| 用法 | 判定 |
|---|---|
| AI 出细纲 + 人工写正文 | 允许 |
| AI 出初稿 + 人工改写 ≥30% | 允许 |
| AI 直出、无实质改写 | 不允许 |
| 中后期文风突变 | 触发动态审核 |

## 三、多平台换挡表（番茄 ↔ 起点）

同一本书换平台，不是改几个字，是改工程参数。

| 项 | 番茄 | 起点 |
|---|---|---|
| 单章字数 | 以 `_PROFILES.json` 为准（偏短） | 以 `_PROFILES.json` 为准（偏长） |
| 前 300 字 | 必须出异常 | 可稍缓，但不得超一屏 |
| 黄金三章 | 3 章内完成兑现 | 5-8 章完成第一轮 |
| 爽点周期 | 每 2 章一个小爽 | 每 5 章一个小高潮 |
| 对话占比 | 30-45% | 25-40% |
| 内心独白 | 少，靠外部事件推进 | 可以大量，允许长心结 |
| 世界观交代 | 极简，边打边给 | 可适度铺陈 |
| 章末钩子 | 强烈，必须断在未完成 | 可稍缓，允许意境收束 |
| 卷长 | 20-40 万字 | 30-60 万字 |
| 主角成长 | 快，10 万字内质变一次 | 可慢，重积累感 |
| 金手指 | 早给，代价后置 | 可晚给，先立人物 |
| 反派 | 频繁更换，层级递进 | 可长线同一对手 |
| 结局 | 兑现明确 | 可留余味 |

换挡示范（同一段）：

- 番茄版：短句为主，第一句就是异常，三句内出现损失，动作多于心理。
- 起点版：可加一段环境与心理，但主干仍在 300 字内出现；允许把冲突往后放半屏，换更厚的世界观质感。

## 四、赛道与标签

### 赛道状态三分

- 蓝海：供给少、需求在长。
- 均衡：供需匹配。
- 过热：同质化严重。

判定法：看当期榜单前 100 里同赛道占比。**>35% 视为过热**，新人进入要带明显差异化。

### 标签选择

- 一个大热度 + 两个精准 + 一个趋势，总数 ≤5。
- 避开"有量但已被同款占满"的标签。
- 主标签要能对上当期征文方向（有征文时优先）。

### 2026 年被点名的过热方向

规则怪谈同质化、流水线真假千金、无脑甜宠。

### 被低估的方向

45+ 中老年向、乡村/年代奋斗（短剧转化率高）。

## 五、情绪标签与平台匹配

| 情绪标签 | 最契合平台 |
|---|---|
| 打脸爽文 | 番茄 / 七猫 / 飞卢 |
| 极致虐恋 | 晋江 |
| 爆笑反套路 | 番茄 / 飞卢 |
| 悬疑惊悚 | 知乎 / 番茄 |
| 治愈甜宠 | 晋江 / 番茄 |
| 脑洞大开 | 番茄 / 飞卢 |
| 升级逆袭 | 起点 / 纵横 / 飞卢 |
| CP 推拉 | 晋江 |

只选一个主标签。同时挂三个以上，等于没有主色。

## 六、换平台前先问三句

1. 这本书的核心卖点在目标平台还成立吗？
2. 字数、节奏、钩子密度需要改多少？改完还是同一本书吗？
3. 目标平台的标签和赛道，和我的主情绪匹配吗？

三问有一个答不上来，先别换。
