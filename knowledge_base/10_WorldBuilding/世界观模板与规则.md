# 世界观模板与规则

> 用途：搭世界观时按层填写，避免"只有名词，没有规则"。
> 边界：世界观是背景，不是正文。正文里只给"影响主角今天行动"的那一条。

## 一、六层结构

### 1. 基础设定

- 时代/地域/技术水平。
- 社会结构：谁有权、谁有钱、谁被排除。
- 普通人一天怎么过：吃什么、住哪里、怎么赚钱。

### 2. 核心规则（力量/科技体系）

每条规则必须回答：

| 问题 | 说明 |
|---|---|
| 能做什么 | 能力的上限 |
| 代价是什么 | 使用一次要付什么 |
| 限制是什么 | 冷却、条件、盲区 |
| 谁能用 | 血统、身份、训练、资源 |
| 打不过什么 | 明确的克制关系 |

没有代价和限制的能力 = 无代价金手指，必须补。

### 3. 历史与传说

- 只写"影响现在"的历史：战争、灾难、禁令、失踪。
- 传说要能落地：谁信、谁不信、信了会怎样。
- 不要把历史写成编年表；用人物口述、遗迹、禁忌带出。

### 4. 重要地点

每个地点记录：

- 位置、到达方式、通勤成本。
- 谁能进、需要什么权限。
- 消费水平、治安、监控。
- 场景用途：谈判、冲突、调查、休整、藏匿。

### 5. 文化习俗

- 称呼、礼节、禁忌。
- 节日、仪式、婚丧。
- 语言习惯：口头禅、脏话、敬语。

文化习俗用来制造冲突和辨识度，不是用来堆设定。

### 6. 伏笔与悬念

- 这个世界有什么"没人解释"的现象。
- 谁在隐瞒什么。
- 主角的认知盲区在哪里。

## 二、世界观写作纪律

1. **只给当前场景需要的规则**。不要在第一章讲完整个大陆。
2. **规则必须通过行动展示**，不要用旁白说明书。
3. **规则一旦建立，不得临时改**。要改，先写变更记录。
4. **每条规则都要能制造冲突**。不能制造冲突的设定，删。
5. **设定服务人物**。人物不关心的设定，读者也不会关心。

## 三、世界观自检

- 这个世界的最主要矛盾是什么？
- 主角在这个世界处于什么位置？被什么限制？
- 力量/科技体系的代价是什么？
- 有没有"只有作者知道"的规则？如果有，什么时候揭示？
- 读者在前三章需要知道哪 3 条规则？其余的能不能后置？

## 四、与项目文件的关系

- 通用方法：本文件。
- 单本小说设定：`设定/世界观/`、`设定/真相文件/`。
- 正文约束：`摘要/chapter_NNN_rule_stack.json` 与 `素材/chapter_NNN_truth_brief.md`。
- 设定变更：先写 `变更记录.md`，再改真相文件，再重跑 `pre`。
