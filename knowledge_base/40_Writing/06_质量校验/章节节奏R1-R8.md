# 章节节奏 R1-R8

> 用途：跨章检查爽点、钩子、字数和憋屈释放，防止"单章没问题、连读十章一个样"。
> 机检：`python tools/chapter_rhythm.py --table 作战表.md --check`；生成骨架：`python tools/chapter_rhythm.py --gen 10 --out 作战表.md`。
> 表格列：`章 | 爽点类型 | 钩子强度 | 字数`。缺列时按 `章/爽点/钩子/字数` 顺序解析。

## 一、R1-R8 规则

| 编号 | 检查 | 阈值 | 严重度 |
|---|---|---|---|
| R1 | 每 3 章至少一次小高潮 | 连续 3 章无高强度爽点 | 警告 |
| R2 | 每 10 章至少一次大反转 | 连续 10 章无身份反转/生死博弈 | 警告 |
| R3 | 连续 3 章同类型爽点 | 读者审美疲劳 | 提示 |
| R4 | 连续 3 章弱钩子 | 追更比受损 | 警告 |
| R5 | 第 3 章前未出现高强度爽点 | 身份反转/生死博弈/打脸/能力兑现 | 严重 |
| R6 | 身份反转占比 | 建议 ≥15% | 提示 |
| R7 | 憋屈后 3 章内必须有释放 | 受辱/铺垫后无释放 | 警告 |
| R8 | 单章字数偏离目标区间 | 按平台 `_PROFILES.json` | 提示 |

## 二、爽点类型与强度

| 类型 | 强度 | 用法 |
|---|---|---|
| 身份反转 | 高 | 卷级，每卷 2-3 次 |
| 生死博弈 | 高 | 有不可逆代价 |
| 打脸 | 高 | 频率最高，注意别同型连发 |
| 能力兑现 | 高 | 升级/技能首次生效 |
| 信息差兑现 | 中 | 读者早知道的伏笔收网 |
| 规则破局 | 中 | 用世界规则本身反杀 |
| 关系推进 | 中 | 信任/和解/表白 |
| 日常锚点 | 低 | 生活质感，别连续太多 |
| 受辱/铺垫 | 低 | 必须尽快接释放 |

## 三、钩子强度

| 强度 | 定义 | 例子 |
|---|---|---|
| 强 | 读者必须点下一章 | 未完成行动、不可撤回选择、身份被认出 |
| 中 | 有期待但不急 | 意外信息、新问题出现 |
| 弱 | 情绪悬置/日常收束 | 关系推进、日常锚点 |

连续弱钩子 3 章 = R4。章末钩子连续不超过 3 章（见 `40_Writing/06_质量校验/章节节奏R1-R8.md` 与 `30_Plot/六台账与20条毒点.md` 的配额表）。

## 四、场景节点与节奏

一个场景只固定两端：

- **目标**：主角从"没意愿"到"有意愿"。
- **结果**：必须与目标留下差距，不许圆满。

外部推进四节点：行动 → 阻碍 → 助力 → 转向。主要场景行动 + 阻碍至少 3 轮。

内部处理四节点：反应 → 消化 → 选择 → 决定。内化不能省，否则主角变执行机器。

四类场景配比：

| 类型 | 特征 | 用途 |
|---|---|---|
| 讲述场景 | 旁白为主 | 开篇铺场、交代背景 |
| 次要场景 | 阻碍很少 | 赶路、日常过渡 |
| 内心场景 | 对上一场结果的反应 | 消化、选择、决定 |
| 主要场景 | 行动 + 阻碍 ≥3 轮 | 战斗、对决、关键揭示 |

一章以 1 个主要场景为轴，配若干次要/内心场景。全章都是主要场景会疲劳，全是次要场景会无聊。

## 五、情绪温度五档

| 档 | 名称 | 每卷占比 | 特征 |
|---|---|---|---|
| 1 | 冷 | 10-15% | 日常、铺垫、关系推进 |
| 2 | 温 | 20-25% | 小冲突、小兑现 |
| 3 | 热 | 30-35% | 主线推进、正面对抗 |
| 4 | 爆 | 15-20% | 大兑现、大反转 |
| 5 | 极爆 | 5-10% | 卷末级事件 |

五条铁律：

1. 同档不得连续超过 4 章（冷档可到 2 章）。
2. 冷档之后必须接热档，不许冷接冷。
3. 极爆每卷 ≤2 次。
4. 每卷必须有一次从冷直接跳极爆的反差。
5. 卷末最后一章必须是爆或极爆。

## 六、憋屈—释放循环

标准节奏：**1 章建立 → 2 章加压 → ≤3 章小释放 → 8-10 章大释放**。

- 加压阶段每次换一种压力源（人、规则、时间、关系）。
- 小释放不等于打脸，可以是暂时脱身、拿到信息、争取到机会。
- 大释放必须支付前面埋下的代价。

## 七、使用方式

1. 先写章节作战表（章/爽点/钩子/字数）；可用 `tools/chapter_rhythm.py --gen N --out 作战表.md` 生成骨架，再按本书设定填写。
2. 跑 `tools/chapter_rhythm.py --table 作战表.md --check`。
3. 先修 R5（前三章无高强度爽点），再修 R1/R4，最后看 R2/R3/R6/R7/R8。
4. 修完重跑，直到只剩提示级问题。
5. 作战表与实际正文不一致时，以正文为准，回填作战表。
