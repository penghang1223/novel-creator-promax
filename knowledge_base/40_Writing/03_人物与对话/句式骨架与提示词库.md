# 句式骨架与提示词库

> 用途：写不出来时的"零件"，以及给 AI 下指令时的粒度控制。
> 铁律：**骨架可用，句子必须自己长出来。** 直接套用会同时踩中"AI 味"和"抄袭感"。
> 边界：本文件是零件库，不是模板库；填 60%，剩下 40% 必须来自本书设定。

## 一、开篇五句链

| 句位 | 功能 | 骨架 | 反面 |
|---|---|---|---|
| S1 异常 | 一件不该发生的事 | "{场景}里，{本该 X 的东西} 正在 {非 X 的状态}。" | "那是一个晴朗的早晨" |
| S2 代价 | 已经或即将失去什么 | "再过 {时限}，{具体损失} 就收不回来了。" | "他知道，事情不简单" |
| S3 反应 | 第一个动作 | "他把 {物件} {动作}，{一个不合常理的细节}。" | "他心中一惊" |
| S4 信息差 | 读者比旁观者多知道 | "只有他知道，{一句反常识的事实}。" | "其实这一切都是阴谋" |
| S5 缺口 | 没完，且必须处理 | "{人} 还在等他给一个说法。" | "接下来会发生什么呢？" |

## 二、章末钩子 12 型

H1 未完成行动 / H2 意外信息 / H3 不可撤回选择 / H4 后果扩大 / H5 身份揭穿 / H6 规则失效 / H7 时间压迫 / H8 关系反转 / H9 代价显形 / H10 目标转移 / H11 视角切换 / H12 悬置动作。

选型纪律：相邻两章不同型；同卷同型 ≤4 次；钩型必须与本章情绪匹配。

## 三、微钩子（每 500 字一个）

三种零件：

1. **信息缺口**：说了一半、留一个没解释的名词。
2. **异常细节**：一个不该有的东西（多出来的杯子、反着放的鞋）。
3. **小型倒计时**：一个具体时限（半小时、天黑前、药效过了）。

用法：不要三个连用，交替使用；每个微钩子都要在后文结算。

## 四、爽点桥段配比（1 : 1.5 : 0.5）

| 段 | 占比 | 内容 |
|---|---|---|
| 铺垫 | 1 | 让对手先把话说满、把姿态做足 |
| 引爆 | 1.5 | 主角用**对方刚说过的话/刚用过的规则**反杀 |
| 余韵 | 0.5 | 旁观者反应 + 一个具体后果（不是总结） |

十类常见桥段：打脸、身份揭穿、规则反杀、以弱胜强、救人立信、夺宝、比试、谈判、复仇、翻案。

## 五、打脸三刀

1. **断言**：让对手公开说一句绝对的话。
2. **双重反转**：先让他赢一半，再让他输掉全部。
3. **传染**：让旁观者的态度跟着变。这一刀最重要，也最多人漏掉。

## 六、转场五类

- 同场景时间跳：动作接续 / 物件变化 / 光线变化。
- 跨场景：人物移动的目的 / 声音先到 / 他人的一句话带过。
- 跨时间：结果先出现 / 后文回指 / 一句状态变化。
- 视角切换：另一个人正在做的事 / 同一件事的另一侧。
- 章节首句：直接动作 / 直接对话 / 直接结果。

禁用"第二天早上""与此同时"作为默认转场。

## 七、金手指三阶段揭示

| 阶段 | 字数区间 | 揭示什么 | 不揭示什么 |
|---|---|---|---|
| 一 | 0-10 万 | 能做什么 | 为什么是他 |
| 二 | 10-50 万 | 代价是什么 | 来源 |
| 三 | 50 万+ | 从哪来、谁给的 | —— |

违反顺序的后果：开篇讲来源 = 悬念提前用光；永远不讲代价 = 爽点失去紧张感。

## 八、书名造词机

四类词池：身份词（赘婿/弃少/门卫/影帝）｜能力词（签到/复制/回溯/演化）｜物件词（玉简/工牌/旧照片）｜量级词（万古/百年/亿万）。

六种公式：身份 + 反转｜能力 + 代价｜物件 + 秘密｜量级 + 身份｜否定 + 常规｜时间 + 处境。

## 九、提示词四类与五条禁忌

> 完整 24 组场景指令见 `novel_creation_promax/references/prompt-library.md`；本节只保留分类与禁忌。

24 组提示词分为四类：

| 类 | 用途 |
|---|---|
| 创作类 | 开篇、章节、对话、场景、反转 |
| 设计类 | 世界观、人物、势力、金手指、大纲 |
| 包装类 | 书名、简介、标签、封面 |
| 质检类 | 一致性、节奏、去 AI 味、数据诊断 |

五条禁忌：

1. 不给指标、格式、验收清单——读起来像验收标准，AI 就交应试作文。
2. 不一次塞入整本设定；只给本章需要的。
3. 不用"写得自然一点"这类空指令；给具体方向、经验、例子。
4. 不把提示词当模板逐字套；每次按本书设定改 40%。
5. 不让提示词替你做创作决策；剧情走向由作者拍板。

## 十、使用纪律

1. 骨架只填 60%，剩下 40% 必须来自本书的具体设定。
2. 同一型号（H1-H12）连续使用不超过 2 章。
3. 任何一句写出来之后自问：**这句换成别的书也成立吗？** 成立就重写。
4. 不许直接搬用他人的具体句子、专名、意象组合。
5. 零件是"写不出来时"用的，不是"每章都套"用的。
