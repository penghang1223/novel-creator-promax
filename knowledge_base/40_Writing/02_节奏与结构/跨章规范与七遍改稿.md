# 跨章规范与七遍改稿

> 用途：单章看不出问题、连着读十章就露馅的"结构级 AI 味"，以及改稿顺序。
> 机检：`tools/chapter_rhythm.py --table 作战表.md --check`、`tools/ai_flavor_score.py`。
> 核心认知：**改句子没用，得改配额。**

## 一、13 条"进度表"病

| # | 症状 | 具体表现 |
|---|---|---|
| 1 | 开局报时 | 第二天清早 / 日头偏西 / 后半夜他醒了 / 天刚亮 |
| 2 | 结尾必留钩子 | 每章最后都抛新信息，读者知道"反正结尾有料" |
| 3 | 主角替别人解释动机 | "她在试我""他在赌"，但本章没有依据 |
| 4 | 道具重复 | 上一章粥，这一章药，下一章还是粥 |
| 5 | 动作口癖 | 每章都"背着手""没说话""记一笔" |
| 6 | 对话全在推进剧情 | 没有闲聊、跑题、误解 |
| 7 | 章节结构同构 | 时间开场→对话→冲突→发现→钩子 |
| 8 | 故作高深的台词 | 角色没有理由想到那句 |
| 9 | 情绪同构 | 每章都有一次顿悟/释然/心口一紧 |
| 10 | 场景同构 | 突破总在山洞、对话总在客栈 |
| 11 | 信息投喂均匀 | 每章新设定数量几乎一样 |
| 12 | 人物登场雷同 | 都靠"先闻其声"或"背影转过来" |
| 13 | 收尾句式家族 | 他知道……/有些事……/从这一刻起…… |

## 二、跨章配额硬指标

| 指标 | 阈值 |
|---|---|
| 时间/醒来类开场 | 每 10 章 ≤2 次；至少 3 章用动作/对话/物件/结果开场 |
| 平淡收尾 | 每 10 章 ≥3 章 |
| 钩子结尾 | 连续不超过 3 章 |
| 同一道具 | 每 5 章 ≤2 次 |
| 氛围道具（灯焰/风/雨/茶凉） | 一章 ≤1 次；第二次出现必须有当场成因 |
| 低事件密度章 | 每 5 章 ≥1 章 |
| 转场写法 | ≥3 种轮换 |
| 叙述层感叹号 | 一章 ≤5 个 |

唯一判断标准：删掉这个时间/道具/台词，剧情压力和理解会不会受损？

## 三、上下文污染与四道边界

AI 拿错信息位置，比"记得少"更常见。

### 四道边界

| 边界 | 内容 | 操作 |
|---|---|---|
| 内容边界 | 先分清哪些是当前依据 | 只给已确认事实，草稿/建议不混入 |
| 任务边界 | 只给当前任务真正需要的信息 | 写章不喂全书，审稿不喂写作提示 |
| 视角边界 | 创作/校验/读感各用一套上下文 | 写手看任务书，审稿看正文+规则 |
| 决策边界 | 建议、草稿、事实不能自动互换 | 候选必须经确认才入库 |

每次投喂资料前问三句：这是事实还是草稿？这是本章需要还是全书背景？这是给写手还是给审稿？

## 四、七遍改稿顺序

| 遍 | 改什么 | 不改什么 |
|---|---|---|
| 1 | 结构：场景顺序、删场、并场 | 句子 |
| 2 | 人物：动机、弧线、关系变化 | 文风 |
| 3 | 表演性中文：排比、空泛结论、总结句 | 事实 |
| 4 | 句法：长短句、主语、语序 | 情节 |
| 5 | 词汇：AI 词、套话、抽象名词 | 叙事 |
| 6 | 标点与格式 | 内容 |
| 7 | 朗读：听感、卡顿、重复 | 一切 |

只改"怎么说"，不改"说什么"；改稿不是重写，除非结构已经坏了。

## 五、表演性中文五类

1. 排比三连：三个同构短语/句子。
2. 空泛结论：这段话说明了……/由此可见……。
3. 万能景物：风轻轻吹过，仿佛在诉说……。
4. 情绪标签：他感到一阵难以言喻的愤怒。
5. 金句癖：每段都想留一句"值得划线"的话。

## 六、虚构专属判据

### 每场戏必须改变 7 项之一

信息 / 关系 / 计划 / 风险 / 权力 / 理解 / 情绪。

一场戏结束，这七项至少有一项与开场不同。全都没变 = 这场戏可以删。

### 救场黑名单

- 突然来一个更强的敌人。
- 突然获得新能力。
- 突然有人解释一切。
- 突然做梦/回忆。
- 突然时间跳跃。

### 对白七种意图

推进 / 暴露 / 关系 / 情绪 / 误导 / 拖延 / 收束。

每句台词至少占一种；既不推进也不暴露，就是在水。

### 性格四问（替代形容词标签）

1. 遇到危险时，他第一反应是什么？
2. 被冒犯时，他先动手还是先忍？
3. 面对利益时，他先算账还是先讲情？
4. 独自一人时，他会做什么？

### 结尾正确落点

- 停在未完成行动。
- 停在意外信息。
- 停在一个不可撤回的选择。
- 不要停在总结、抒情、升华。

## 七、修订铁律

1. 能改一个词就不改一句，能删一句就不重写一段。
2. 不新增事实、数字、案例、因果、引语。
3. 原文明示限定词（可能/通常/据说）不得抹掉。
4. 判断强度不得加重。
5. 改完朗读一遍，听感不对就回退。
6. 每遍只改一类问题，不混着改。
