# 人物声线与弧线卡

> 用途：防止千人一面、角色 OOC、关系无铺垫。写章前的任务书人物段直接用这里的字段。
> 边界：本文件是通用方法；单本小说的人物状态仍写入 `设定/真相文件/characters.json` 与项目角色卡。

## 一、Egri 三维角色

| 维度 | 问题 | 例子 |
|---|---|---|
| 生理 | 年龄、性别、外貌、健康、缺陷 | 28 岁，右手旧伤，写字会抖 |
| 社会 | 职业、阶层、家庭、教育、关系 | 被裁的律所助理，单亲，租房 |
| 心理 | 欲望、恐惧、底线、矛盾 | 想证明自己，怕被可怜，底线是不欠人情 |

三维缺一维，人物就扁。最常见的缺失是"心理矛盾"——只有目标，没有恐惧和底线。

## 二、角色弧线（Weiland）

| 阶段 | 内容 |
|---|---|
| 谎言 | 角色相信一个错误信念（我不需要任何人） |
| 伤口 | 过去发生了什么让他相信这个谎言 |
| 欲望 | 他以为自己想要的（赢回前夫） |
| 需求 | 他真正需要的（学会独立） |
| 转折 | 谎言被现实击穿 |
| 新信念 | 他接受真相，做出不同选择 |

弧线不是"成长"两个字；它必须能说清"他原来信什么、后来信什么"。

## 三、声线卡（最关键）

用**高频词 / 句式特征 / 比喻域**三维差异化。遮住名字能分辨谁在说话。

| 角色类型 | 高频词 | 句式特征 | 比喻域 |
|---|---|---|---|
| 理性型 | 逻辑/所以/问题在于 | 长句、分析式 | 科学类比 |
| 感性型 | 那个/好美/我忍不住 | 柔和长句 | 自然/地质类比 |
| 焦虑型 | （省略主语）/糟了 | 超短句、急促碎片化 | —— |
| 痞气型 | 爷/没啥大不了/啧 | 口语化、反问多 | 市井类比 |

### 声线卡模板

```text
【角色名】
高频词：xxx / xxx
句式特征：xxx
比喻域：xxx
口头禅：xxx（遇难题/情绪时出现）
禁止语：本角色绝不会说 xxx
```

## 四、反派设计

1. **从自身视角行为合理**：反派认为自己是主角，有自己的道德逻辑。
2. **与主角共享同一 Wound**：被同一个创伤塑造，只是走向不同。
3. **某个时刻让读者动摇**：让读者怀疑"也许他们是对的"。

扁平反派 = 工具人。真正的反派能映照主角，是"另一个可能的自己"。

## 五、对话辨识度测试

- 遮住名字，能否判断谁在说话？
- 每个人说话长度、用词、口头禅、反应速度都不同。
- 焦虑型急着多说、理性型慢条斯理、痞气型爱反问。
- 角色不能说出超出身份、教育、时代的话。

## 六、关系矩阵（连续性台账）

| | 角色A | 角色B | 角色C |
|---|---|---|---|
| 角色A | —— | 旧怨新和（X章） | 师徒 |
| 角色B | 旧怨新和（X章） | —— | 敌对 |
| 角色C | 师徒 | 敌对 | —— |

记录关系变化触发章节，防止"昨天敌人今天挚友"无铺垫反转。

## 七、人物档案模板

```text
基本信息：姓名 / 年龄 / 身份 / 外貌
性格核心：主导特质 / 矛盾特质 / 核心恐惧 / 核心渴望 / 底线
背景故事：出身 / 关键创伤 / 转折事件
行为模式：压力反应 / 决策逻辑 / 不会做的事
能力边界：会什么 / 不会什么 / 代价 / 打不过谁
声线：高频词 / 句式 / 比喻域 / 口头禅 / 禁止语
关系：与主要角色的信任等级、冲突、信息差
成长方向：从什么信念到什么信念
```

## 八、人物一致性检查

1. 行为是否符合动机、恐惧、底线？
2. 说话是否符合声线卡？
3. 能力是否超出当前层级？
4. 是否知道不该知道的事？
5. 关系变化是否有叙事支撑？
6. 首次出场是否通过行动/对话，而不是简历式介绍？
7. 配角是否有自己的"眼下要办的事"？

## 九、首次出场原则

- 不要写"我叫 XX，今年 X 岁"。
- 让人物在做事、做选择、犯错误中出场。
- 第一印象要有一个具体细节（手上的伤、说话的习惯、一个不合时宜的动作）。
- 配角出场只留 2 个，其余用身份代称，避免"会议点名册"。
