# 叙事结构与场景节点

> 用途：搭大纲、拆卷、写单章时选择结构骨架；卡文时用场景节点定位问题。
> 边界：结构是脚手架，不是铁轨。细纲偏离仍需按项目偏离协议处理。

## 一、Save the Cat! 15 节拍（长篇主线）

| # | 节拍 | 作用 |
|---|---|---|
| 1 | 开场画面 | 主角当前状态 |
| 2 | 主题陈述 | 一句话点出本书主题 |
| 3 | 铺垫 | 展示缺陷与日常 |
| 4 | 催化剂 | 打破日常的事件 |
| 5 | 争论 | 主角犹豫 |
| 6 | 进入第二幕 | 做出选择 |
| 7 | B 故事 | 关系/副线登场 |
| 8 | 游戏与承诺 | 兑现题材卖点 |
| 9 | 中点 | 假胜利/假失败，赌注升级 |
| 10 | 坏人逼近 | 压力升级 |
| 11 | 一无所有 | 失去关键东西 |
| 12 | 灵魂黑夜 | 主角最低点 |
| 13 | 进入第三幕 | 找到新方法 |
| 14 | 结局 | 最终对决 |
| 15 | 终场画面 | 与开场对照 |

网文不需要严格 15 拍，但"中点升级、一无所有、灵魂黑夜、终局对照"四个节点最好有。

## 二、Story Circle（章级 8 步）

1. 舒适区
2. 想要什么
3. 进入不熟悉处境
4. 适应
5. 得到想要
6. 付出代价
7. 回到熟悉处境
8. 已经改变

单章可以套用：主角从"安全状态"到"被迫行动"，最后"带着变化回到日常"。

## 三、MRU 单元（刺激→反应）

最贴近真人反应：

```text
刺激 → 身体反应 → 情绪 → 想法 → 行动
```

写打斗、惊吓、冲突时，按这个顺序写，读者更容易代入。不要跳过身体反应直接写"他决定……"。

## 四、三幕式（中篇/短篇）

| 幕 | 占比 | 内容 |
|---|---|---|
| 第一幕 设置 | 25% | 日常、催化剂、进入冲突 |
| 第二幕 对抗 | 50% | 升级、中点、一无所有 |
| 第三幕 结局 | 25% | 最终对决、新平衡 |

短篇可压缩为：钩子 → 升级 → 反转 → 收束。

## 五、题材结构速查

| 题材 | 核心结构 |
|---|---|
| 悬疑 | 谜题出现 → 调查深入 → 真相揭示（线索必须可回溯） |
| 言情 | 相遇 → 发展/误会 → 和解（关系阶段必须变化） |
| 惊悚/动作 | 威胁出现 → 追逃/对抗 → 生死决战 |
| 反转 | 铺垫 → 误导 → 揭示（反转必须建立在已有信息上） |
| 多线 | 交叉剪辑/时间线 → 收敛（支线必须回到主线） |

## 六、钩子四铁律

1. 每章至少一个钩子（章末或章中）。
2. 钩子必须与本章情绪匹配。
3. 钩型必须轮换，相邻两章不同型。
4. 钩子必须结算，不许埋了不管。

### 8 种钩子类型

未完成行动 / 意外信息 / 不可撤回选择 / 后果扩大 / 身份揭穿 / 规则失效 / 时间压迫 / 关系反转。

### 章末 12 型骨架

H1 未完成行动：动作做到一半被打断。
H2 意外信息：一句不该出现的话/一个不该在场的物件。
H3 不可撤回选择：两个选项都要付代价。
H4 后果扩大：波及到不该波及的人。
H5 身份揭穿：被认出来/自己承认/证据落在对方手里。
H6 规则失效：一直管用的办法突然不管用。
H7 时间压迫：期限提前/倒计时被看见。
H8 关系反转：盟友变对手/对手递来橄榄枝。
H9 代价显形：副作用发作/账单送到。
H10 目标转移：原目标作废/新目标更急。
H11 视角切换：切到对手/受害者/旁观者。
H12 悬置动作：举起刀/车灯照过来/电话接通。

选型纪律：相邻两章不同型；同卷同型 ≤4 次。

## 七、场景骨架：目标与结果

一个场景只固定两端：

- **目标**：主角从"没意愿"到"有意愿"。可以主动，可以被动，但必须主动愿意接受。
- **结果**：必须与目标留下差距。达成了要带遗憾或风险，没达成要有其他收获，或转向新目的。不许圆满。

删留判据：这个场景删掉，后文还成立吗？成立 → 删或合并。

## 八、外部推进四节点

| 节点 | 作用 |
|---|---|
| 行动 | 主角开始做事 |
| 阻碍 | 本来能推动，现在推不动 |
| 助力 | 有人/事/物加速 |
| 转向 | 目标不变，改推进方式 |

主要场景的行动 + 阻碍至少 3 轮。一轮就过关的戏撑不起高潮。

## 九、内部处理四节点

反应 → 消化 → 选择 → 决定。

内化不能省。外部打完直接跳下一件事，主角就变成执行机器。

## 十、四类场景与配比

| 类型 | 特征 | 用途 |
|---|---|---|
| 讲述场景 | 旁白为主 | 开篇铺场、交代背景 |
| 次要场景 | 阻碍很少 | 赶路、日常过渡 |
| 内心场景 | 对上一场结果的反应 | 消化、选择、决定 |
| 主要场景 | 行动 + 阻碍 ≥3 轮 | 战斗、对决、关键揭示 |

一章以 1 个主要场景为轴，配若干次要/内心场景。

## 十一、压缩与扩展

- **压缩**：作者旁白直接给结果（"三天后，他到了目的地。"）
- **扩展**：铺成完整场景，目标、行动、阻碍、转向、结果全走一遍。

必须扩展：爽点、战斗、关键情感、关键抉择。
必须压缩：赶路、日常琐事、重复劳动。

## 十二、卡文急救

| 症状 | 可能原因 | 处方 |
|---|---|---|
| 不知道下一句写什么 | 场景没有目标 | 先写"他这场景想要什么" |
| 写着写着没劲 | 结果太圆满 | 给结果留缺口/代价 |
| 角色像工具人 | 没有内部处理 | 补反应→消化→选择→决定 |
| 场景像流水账 | 没有阻碍/转向 | 加一轮阻碍，或换推进方式 |
| 一章写不长 | 该扩展的压缩了 | 扩展爽点/战斗/情感/抉择 |
| 一章写太水 | 该压缩的扩展了 | 赶路/日常用旁白带过 |

## 十三、单章标准结构

1. 开头钩子（前 20%）：异常/损失/具体处境。
2. 发展推进（中间 50-60%）：行动 → 阻碍 → 助力 → 转向。
3. 高潮时刻（后 15-20%）：兑现/反转/代价。
4. 结尾钩子（最后 5-10%）：未完成行动/意外信息/不可撤回选择。

章节类型：情节推进章 / 人物深化章 / 氛围营造章 / 过渡衔接章。四类轮换，避免同构。
